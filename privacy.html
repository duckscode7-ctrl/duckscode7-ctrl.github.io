DUCKS uploader – Privacy Policy

Last updated: October 20, 2026 · Contact: duckscode7@gmail.com

DUCKS uploader is a private command-line tool used only by the owner of the YouTube channels 분양덕, 경제 읽어주는 덕희, 얌얌덕 and 눈나 (all owned by the Google account duckscode7@gmail.com). It uses the YouTube Data API only to upload our own original videos to our own channels.

What we access

  • OAuth scopes: youtube.upload (to upload our videos) and youtube.readonly (to confirm the target channel before each upload).
  • No viewer, subscriber, comment or third-party data is accessed.

What we store

  • Our own channel ID, title and handle, and for each upload the returned video ID, privacy status and upload status.
  • These are stored only in local files on the owner's PC.

Credentials

The OAuth client file and refresh tokens are stored only on the owner's PC, in a folder excluded from version control. They are never shared, uploaded or logged.

Sharing

We do not share, sell or display YouTube data to anyone. The tool has no other users and no public sign-up.

Deletion

Access can be revoked at any time at https://myaccount.google.com/permissions. Deleting the local token file removes our copy.

Google policies

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy. DUCKS uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

DUCKS 업로드 도구 개인정보 처리 안내

마지막 수정: 2026년 10월 20일

DUCKS 업로드 도구는 분양덕, 경제 읽어주는 덕희, 얌얌덕, 눈나 채널(모두 duckscode7@gmail.com 계정 소유)의 주인만 쓰는 개인용 명령어 도구예요. YouTube Data API는 우리가 직접 만든 영상을 우리 채널에 올리는 데만 써요.

  • 접근하는 것: 업로드 권한(youtube.upload)과, 올리기 전에 채널을 확인하는 읽기 권한(youtube.readonly)만 써요. 시청자·구독자·댓글 등 다른 사람의 정보는 보지 않아요.
  • 저장하는 것: 우리 채널의 ID·이름·핸들과, 올린 영상의 ID·공개 상태·업로드 상태만 저장해요. 운영자 PC 안의 파일에만 저장돼요.
  • 인증 정보: OAuth 설정 파일과 토큰은 운영자 PC의 버전 관리 제외 폴더에만 두고, 공유·업로드·기록하지 않아요.
  • 공유: YouTube 데이터를 누구와도 공유하거나 팔거나 보여주지 않아요. 다른 사용자나 공개 가입은 없어요.
  • 삭제: https://myaccount.google.com/permissions 에서 언제든 권한을 끊을 수 있어요. PC의 토큰 파일을 지우면 우리 쪽 사본도 사라져요.
  • 구글 정책: YouTube API 서비스를 사용해요. YouTube 서비스 약관과 Google 개인정보처리방침, Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따라요.
